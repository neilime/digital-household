# digital-household

Reproducible home infrastructure, reliable home automation and personal AI assistance.

Prepare a private Proxmox installation ISO for a compatible host and preview or apply
its host baseline with Docker and GNU Make. Follow the
[Proxmox bootstrap guide](docs/usage/proxmox-bootstrap.md) to identify the disk,
configure networking and verify installation safely.

HAOS and service deployment are still being implemented.

Run `make help` for available commands. See the [documentation](docs/README.md)
for prerequisites, validation and deployment boundaries.
